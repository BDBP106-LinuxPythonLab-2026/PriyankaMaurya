EXPLANATION :- Describe the sequence of keystrokes used in full.

Q11) Insert text at line 70 and change "important" to "critical"

70G - Go directly to line 70.
o - Open a new line below the current line and enter Insert mode.

Type: This is an important reminder for you.
Esc - Exit Insert mode.
/important - Search for the word important.
Enter - Move the cursor to the searched word.
cwcritical - Change the word important to critical.
Esc - Return to Normal mode.

Q12) Note the current line number, jump to the end, and return

Ctrl + G - Display the current line number.
Note the line number (for example, 35).
G - Jump to the last line of the file.
35G - Return directly to line 35 (replace 35 with your noted line number).

Q13) Add a sentence at the end and delete the text inside parentheses

G - Go to the last line.
o - Open a new line below.

Type: The quick brown fox (who was very quick) jumps over the lazy dog.
Esc - Exit Insert mode.
Move the cursor onto the opening parenthesis (.
dw( - Delete everything inside the parentheses including the parentheses.

Final Output: The quick brown fox jumps over the lazy dog.

Q15(i).  Fix spacing issues (Lines 1–3)

1G - Go to line 1.
Use arrow keys or h, j, k, l to move the cursor.
x - Delete extra spaces.
i - Insert missing spaces.
Type the required space.
Esc - Return to Normal mode.
Repeat for lines 2 and 3

Q15(ii). Fix capitalization and typographical errors (Lines 5–8)

5G - Go to line 5.
Move the cursor to the incorrect letter.
~ - Change lowercase to uppercase (or uppercase to lowercase).
If a word is misspelled:
cw
Type the correct word.
Esc
Repeat for lines 6–8.

Q15(iii). Correct punctuation errors (Lines 10–13)

10G Go to line 10.
Move - the cursor to the punctuation mark.
i -Insert missing punctuation.
Type , or . or ; as needed.
Esc - Exit Insert mode.
If punctuation is extra:
Move to it.
Press x to delete.
Repeat for lines 11–13.

Q15(iv). Remove unwanted words (Lines 15–17)

15G - Go to line 15.
Move the cursor to the unwanted word.
dw - Delete the word.
Repeat for lines 16 and 17.
We can also use daw to delete the entire word with the surrounding space.

Q15(v). Fix alignment issues (Lines 19–22)

19G - Go to line 19.
V - Start Visual Line mode.
3j - Select lines 19–22.
>> - Indent the selected lines.
